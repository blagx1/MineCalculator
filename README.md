# MineCalculator 1.0.3

Клиентский калькулятор для Minecraft Java 1.21.11. Проект содержит отдельные адаптеры Fabric, Forge и NeoForge с общей кодовой базой. Сохранены математический движок, история вычислений, а также совместимость с уже существующими настройками и сохранённой историей.

# MineCalculator 1.1 — Changelog

**Обновление с версии 1.0.3 до 1.1**

В версии 1.1 проведена масштабная работа над визуальной частью MineCalculator, структурой проекта, оформлением интерфейса и поддержкой различных загрузчиков Minecraft.

## ✨ Интерфейс и визуальные улучшения

- Обновлено оформление интерфейса калькулятора.
- Улучшена компоновка боковой панели.
- Переработано расположение кнопки сворачивания боковой панели.
- Изменён размер кнопки сворачивания до 26×24 пикселей.
- Увеличен масштаб кнопки до 1.55.
- Область нажатия кнопки синхронизирована с её визуальным размером.
- Сохранена возможность сворачивания боковой панели с использованием иконок.
- Продолжены улучшения визуальных элементов и общей согласованности интерфейса.

## 🔤 Шрифты

- Продолжена интеграция шрифта Hardenne.
- Добавлены необходимые файлы шрифта для NeoForge.
- Добавлена конфигурация `hardenne.json`.
- Добавлен файл `hardenne.ttf`.
- Улучшена согласованность ресурсов шрифта между загрузчиками.

## 📦 Структура и организация проекта

- Версия проекта унифицирована до 1.1.
- Обновлён `VERSION.txt`.

- Приведены к единому формату названия сборок.
- Упорядочена структура многозагрузочного проекта.
- Подготовлены отдельные исходные модули для Fabric, Forge и NeoForge.

## 🎮 Загрузчики Minecraft
