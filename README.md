# MineCalculator 1.0.3

Клиентский калькулятор для Minecraft Java 1.21.11. Проект содержит отдельные адаптеры Fabric, Forge и NeoForge с общей кодовой базой. Сохранены математический движок, история вычислений, а также совместимость с уже существующими настройками и сохранённой историей.

## Требования

- Minecraft Java Edition 1.21.11
- Один из загрузчиков: Fabric, Forge или NeoForge (версии указаны в `gradle.properties`)
- JDK 21
- IntelliJ IDEA
- Gradle 9.x (Fabric Loom 1.14.10)

## Открытие и сборка

1. Распакуйте архив в обычную папку, например `C:\MinecraftDev\MineCalculator`.
2. Откройте папку `MineCalculator` в IntelliJ IDEA.
3. Выберите JDK 21 для Gradle JVM.
4. Дождитесь синхронизации Gradle.
5. Выполните `.\gradlew.bat :fabric:build` из корня проекта.
6. Готовый файл `MineCalculator-1.0.3.jar` появится в `fabric/build/libs/`.

В этом архиве Gradle Wrapper не поставляется. Если в твоей рабочей папке уже есть `gradlew.bat`, используй команду `.\gradlew.bat :fabric:build`. Если файла нет, один раз создай Wrapper из корня проекта командой `gradle wrapper`, затем собирай мод привычной командой `.\gradlew.bat :fabric:build`.

## Управление

- K — открыть / закрыть MineCalculator по умолчанию; клавишу можно изменить в разделе «Управление».
- Enter — вычислить выражение по умолчанию; переназначается в «Управление».
- Backspace — удалить последний символ.
- Delete — очистить выражение по умолчанию; переназначается в «Управление».
- Escape — закрыть окно по умолчанию; переназначается в «Управление».
- Ctrl+C — скопировать результат.
- Мышь — перетаскивание окна за верхнюю панель, выбор разделов, настройка ползунков.
- Колесо мыши и полоса прокрутки — перемещение по истории.

## Возможности 1.0.3

- Совместимый математический модуль без зависимости от Minecraft/Fabric API.
- Безопасный рекурсивный парсер без `eval`, вычисления через `BigDecimal`.
- Сложение, вычитание, умножение, деление, скобки, унарный минус, десятичные числа и проценты.
- Пять разделов интерфейса: калькулятор, история, внешний вид, управление и дополнительно.
- Четыре темы: синяя, фиолетовая, бирюзовая и светлая; текст без теней.
- Ползунок масштаба 50–100% с шагом 1% и ползунок прозрачности 40–100%.
- Квадратные переключатели с заливкой и отметкой при включении.
- Увеличенные иконки, мягкое скругление окна, панелей и кнопок.
- Анимации открытия/закрытия, переходов, наведения и появления результата; их можно отключить.
- История последних 10 успешных вычислений с сохранением, повтором выражения и копированием результата.
- Переназначение горячих клавиш с проверкой конфликтов.
- Звуки и настройки звука полностью удалены.
- Сохранение положения окна и коррекция его позиции при смене разрешения.
- Сохранение совместимости со старыми `settings.properties` и `history.tsv` в папке `config/minecalc`.

## Данные пользователя

Настройки хранятся в `.minecraft/config/minecalc/settings.properties`, история — в `.minecraft/config/minecalc/history.tsv`. Старые настройки масштаба мигрируют в новый диапазон 50–100%; прежние значения выше 100% ограничиваются до 100%.

## Мультиплатформенная структура (подготовка)

- `common/` — независимые математические вычисления, настройки и история.
- `client-common/` — единый экран Minecraft, используемый платформенными адаптерами.
- `fabric/` — Fabric entrypoint.
- `forge/` — Forge entrypoint и `mods.toml`.
- `neoforge/` — NeoForge entrypoint и `neoforge.mods.toml`.

Для каждой платформы предусмотрена отдельная сборка:
- `:fabric:build`
- `:forge:build`
- `:neoforge:build`

**Статус:** это первый этап переноса общей клиентской части и добавления платформенных адаптеров. Полные Gradle-сборки и запуск Minecraft для Forge/NeoForge ещё должны быть выполнены в среде с JDK 21 и доступом к репозиториям Gradle. До такой проверки не следует публиковать новые JAR как готовые релизы.
